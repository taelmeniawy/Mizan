# Mizan — ميزان

> نظام ERP ومحاسبة تجاري لسطح المكتب، مخصّص لمتجر مستلزمات كهربائية وأدوات (hardware) في مصر.
> **المراحل 1–8 منفذة ومختبرة (نواة بلا واجهة UI). المرحلة 7 تنتظر اختبار الطباعة الفعلية. المرحلة 9 قيد التنفيذ الجزئي: النسخ المتحقق والمشفّر، والاستعادة، والجدولة والاحتفاظ، والنسخة خارج الجهاز، وعرض سجل التدقيق، وفحص بدء التشغيل منفذة ومختبرة.**

## الغرض من المنتج

**Mizan (ميزان)** تطبيق Windows Desktop لمتجر واحد، ومخزن واحد، وجهاز واحد في V1. يهدف إلى إدارة العمليات التجارية اليومية لمتجر مستلزمات كهربائية وأدوات — بيع التجزئة والجملة والمقاولين، الشراء من الموردين، المخزون بدفعات FIFO، تتبّع بكرات الأسلاك، الحسابات المالية، وعروض الأسعار — مع **محاسبة قيد مزدوج** حقيقية، لا مجرد تسجيل أصناف وطباعة فواتير.

المنتج مصمّم للعمل **دون اتصال بالإنترنت**، بواجهة **عربية RTL**، وبعملة **الجنيه المصري (EGP)** فقط في V1.

## اصطلاحات الوثائق

| المصطلح | المعنى |
|---|---|
| **CONFIRMED** | متطلب أو قرار ورد صراحةً في مصدر المتطلبات المعتمد لهذه الدفعة، ويجب الحفاظ عليه. |
| **PROPOSED** | توصية هندسية أو منتجية من فريق التوثيق، **لم يعتمدها المالك بعد**. |
| **OPEN QUESTION** | قرار يتطلب إجابة المالك، ومسجّل في `10_OPEN_QUESTIONS.md`. لا يُفترض أن قيمة غيابه «لا شيء». |
| **غير محدد حتى الآن** | لا توجد معلومات كافية؛ لا يُخترع بديل. |
| **مثال توضيحي** | أرقام افتراضية للشرح فقط، وليست بيانات عمل أو أسعارًا حقيقية. |

- الوثائق مكتوبة بالعربية، مع إبقاء المعرّفات التقنية وأسماء الجداول والحقول والواجهات بالإنگليزية.
- كل مبلغ نهائي أو قيد يومية يُخزَّن ويُعرض بدقة **القرش** (integer piastres) وفق ADR-0003.
- كل كمية مخزون تُخزَّن كعدد صحيح بوحدة أساس مضروبة في مقياس ثابت؛ لا تُستخدم أعداد عشرية عائمة.
- الأمثلة الرقمية في الوثائق **توضيحية** ما لم يُنص صراحةً على أنها بيانات مالك معتمدة.

## ما لم يحدث في Batch 1 (تاريخي)

- لم يُكتب أي كود تطبيق أو اختبارات.
- لم تُنشأ أي قاعدة بيانات أو ترحيلات (migrations).
- لم تُثبّت أي حزم أو تغيّر بيئة الجهاز.
- لم يُهيّأ Git ولم يُنشأ مستودع.
- لم تُنفّذ أي ميزة، ولم يُدّعَ تنفيذ أو اختبار أي شيء.
- لم تُتخذ قرارات عمل غير واردة في المصدر؛ كل ما هو غير محسوم مسجّل كسؤال مفتوح.
