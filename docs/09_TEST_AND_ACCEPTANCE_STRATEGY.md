## 1. مبادئ الاختبار

| المعرّف | المبدأ |
|---|---|
| TEST-P-001 | اختبارات النواة (محاسبة/FIFO/بكرات/تقريب) إلزامية قبل أي ترحيل إنتاجي. |
| TEST-P-002 | اختبار القيود على مستوى قاعدة البيانات نفسها (SQLite مرشحة)، لا الواجهة فقط. |
| TEST-P-003 | كل فشل ترحيل يجب أن يثبت `rollback` كاملًا. |
| TEST-P-004 | لا تُعدَّل بيانات اختبار إنتاجية؛ fixtures معزولة. |
| TEST-P-005 | الاختبارات لا تعتمد على ترتيب عشوائي غير حتمي. |
| TEST-P-006 | اختبارات PDF لا تُستبدل بـMicrosoft Print to PDF. |
| TEST-P-007 | اختبار الاستعادة يشمل قاعدة البيانات والمستندات. |
| TEST-P-008 | أي قرار OPEN لا يُختبر كأنه معتمد؛ يُختبر كسيناريو شرطي. |

## 2. طبقات الاختبار

| الطبقة | النطاق | أمثلة |
|---|---|---|
| Static/Domain | Value Objects، الحساب، التقريب | Decimal/Fraction، تحويل وحدات، توزيع خصم |
| Unit | خدمات نطاق منعزلة | FIFO allocator، reel cutter، pricing resolver |
| Integration/DB | SQLite، FKs، partial indexes، triggers | منع التكرار، منع الازدواج، القيود |

| UI/Manual | RTL/UX/طابعة | شاشات، رسائل، طباعة حقيقية |
| Backup/Restore | Online backup + manifest | استعادة، hash، فتح DB |
| Regression | سيناريوهات تاريخية | عدم تغيير تكاليف/مستندات |

## 15. القبول اليدوي

- مراجعة RTL على شاشة 1366×768 و1920×1080.
- طباعة فاتورة/عرض/كشف على A4 حقيقية.
- مراجعة أرقام/تواريخ/عملة مع مالك.
- سيناريو بيع/شراء/مرتجع كامل مع محاسب.
- استعادة نسخة على جهاز/مجلد منفصل.
- مراجعة سجل تدقيق لعملية حساسة.

## 16. ما لا تعتمده هذه الوثيقة

- لا تعتمد أي نتيجة اختبار؛ لم تُشغَّل.
- لا تعتمد LCP؛ تُختبر كمرشحة. B القديم **غير صالح كما هو**، وA تاريخي.
- لا تعتمد المصفوفة/الصلاحيات.
- لا تعتمد A4 renderer/الخط.
- لا يوجد كود اختبار في Batch 1.
